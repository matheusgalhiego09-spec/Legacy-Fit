
# Legacy Fit

### Website Institucional para Academia

O Legacy Fit é um website responsivo desenvolvido para apresentar uma academia de forma moderna, organizada e acessível.

O projeto prioriza a experiência do usuário, a identidade visual e a apresentação clara das informações da academia.

## Funcionalidades

- Layout responsivo para computadores e celulares
- Apresentação institucional da academia
- Informações sobre planos e serviços
- Navegação entre as seções do site
- Links para consulta de planos e elegibilidade

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- Netlify

## Objetivo

Desenvolver uma presença digital profissional para uma academia, aplicando conhecimentos de desenvolvimento front-end, responsividade e organização visual.
